# TypeScript Assignment

This assignment has two parts: a set of TypeScript problem solutions and two short blogs on TypeScript concepts.

## Overview

**Code solutions — [`solutions.ts`](./solutions.ts)**

Small, self-contained TypeScript functions and classes covering:

- Default and optional parameters (`multiplyValue`)
- Union types with type narrowing (`processInput`)
- Readonly tuple types with destructuring (`formatCoordinate`)
- Generics and rest parameters (`concatenateArrays`, `pluckValues`)
- Interfaces with array filtering (`Course`, `getPopularCourses`)
- Classes, inheritance, and access modifiers (`Employee`, `Manager`)
- Async code with Promises (`validateAgeAsync`)

**Blogs**

1. [Type vs Interface in TypeScript: What's the Difference?](./type-vs-interface.md) — syntax of type aliases and interfaces, extension vs intersection, declaration merging, a comparison table, and guidance on when to use each.
2. [Access Modifiers in TypeScript: `public`, `private`, `protected` & `readonly`](./access-modifier.md) — how each modifier controls access, `readonly` properties, parameter properties, and a quick summary table.
